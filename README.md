掘金同步助手是一款 Chrome Manifest V3 浏览器扩展。它读取你主动选择的掘金文章或编辑器草稿，处理正文与图片，再同步到目标平台的草稿箱。所有内容转换均在浏览器本地扩展中完成，直接与源站和目标平台通信，**不依赖任何托管账号密码的中转服务器**。

> ⚠️ **只同步草稿，不自动公开发布。** 同步完成后，请在目标平台检查排版、封面和内容，再自行决定发布。

## 🌟 核心特性与支持平台

| 能力 | 🔴 CSDN | 🟢 微信公众号 | 🔵 博客园 |
| --- | --- | --- | --- |
| 掘金新文章发布后同步、历史文章手动同步 | ✅ 支持 | ✅ 支持 | ✅ 支持 |
| 正文格式 | 📝 Markdown 规范化与平台适配 | 🎨 微信专用 HTML 排版 | 📝 博客园 Markdown 草稿 |
| 正文图片 | 🖼️ 自动转存；失败策略可配置 | 🖼️ 自动转存；失败终止 | 🖼️ 自动转存；失败终止 |
| 源文章封面 | 📌 按偏好设置同步 | 📐 自动上传、裁剪并绑定 | 📌 按偏好设置转存为题图 |
| 文章摘要 | 📌 优先源摘要/截取正文 | 📌 截取前 120 字作为摘要 | 📌 优先源摘要/截取正文 |
| 无封面文章 | ✅ 支持 | ✅ 支持 | ✅ 支持 |
| 代码块 | 💻 保留 Markdown 代码块 | 💻 转换为微信编辑器结构 | 💻 保留 Markdown 代码块 |
| 草稿更新 | 🔄 检查公开发布状态 | 🛡️ 按公众号隔离 | 🛡️ 按博客园账号隔离并检查草稿状态 |

> 💡 三个平台独立执行、独立记录结果。一次勾选多个平台，不代表所有平台都会同时成功。

### 📱 微信同步特别说明

- 🎨 **专属排版**：标题、段落、列表、引用、表格和图片按微信格式重新生成；外链保留为文末编号参考链接，不破坏阅读体验。
- 💻 **代码保真**：代码块使用微信专用 `section / pre / code` 结构，每行一个节点。语言标识来自 Markdown 围栏，支持 `js`、`ts` 等常见别名；未标注时不猜测。
- 📐 **封面裁剪**：源封面上传后自动生成 16:9、1:1、3:4 三套裁剪结果。**没有源封面也能同步**，若微信发布时要求封面，由你在微信后台补充即可。
- 🛡️ **防重更新**：更新失败不会自动盲目转为新建，避免产生重复草稿。保存结果不明确时，需要先核对草稿箱，再决定是否重试。
- 👤 **账号隔离**：任务与草稿映射深度绑定公众号身份。切换账号后，原账号任务不会使用新账号继续写入；未绑定账号的旧微信草稿记录不会被自动覆盖。

## 🚀 安装与升级

### 📦 下载 Release 安装包（推荐）

1. 📥 前往 [Releases 页面](https://github.com/juejin-sync/juejin-sync/releases/latest) 下载最新版 `juejin-sync-v1.3.1.zip` 并解压。
2. 🌐 打开 Chrome 浏览器，访问 `chrome://extensions/`，开启右上角的 **“开发者模式”**。
3. 📂 点击 **“加载已解压的扩展程序”**，选择解压出的目录。
4. 🔑 在同一 Chrome 配置文件中登录掘金和需要同步的目标平台。
5. 🔄 刷新已经打开的掘金页面，让注入脚本生效。

> 💡 **升级提示**：升级时，用新包内容覆盖原加载目录，再在扩展管理页点击“重新加载”🔄即可。保留原安装实例可保留其本地设置和记录；卸载扩展会清除本地数据。升级后同样需要刷新掘金页面。

### 💻 从源码运行

建议使用与 CI 一致的 Node.js 22 和 npm：

```bash
git clone https://github.com/juejin-sync/juejin-sync.git
cd juejin-csdn-extension
npm ci
npm run check
npm test
npm run build
```

然后在 Chrome 扩展管理页加载仓库中的 `dist/` 目录。

## 🛠️ 如何同步

### 🎯 新文章：发布成功后同步

- ✍️ 点击掘金原有的“发布”，在发布表单的 **“多平台同步”** 中选择目标平台。
- ✅ 可选择已登录的 CSDN 和／或微信公众号。此时只记录本次选择，不会立即同步。
- 🚀 点击掘金原有的“确定并发布”。只有掘金发布接口确认成功后，扩展才创建目标平台草稿任务。

取消发布、校验失败或发布接口失败都不会触发同步；目标平台同步失败也不会改变掘金已经发布成功的结果。

### 📚 已发布文章：立即同步

- 🎨 **创作者中心**：在自己的文章管理列表使用“同步多平台”。
- 👤 **个人主页**：在自己文章的操作菜单中使用“同步多平台”。

这两个入口会打开平台选择弹窗，点击“确认同步”后立即创建目标平台草稿任务。刷新登录状态不会重新选中已取消的平台。

### 📊 查看结果和再次同步

点击浏览器右上角扩展图标打开面板，“同步记录”支持查看成功、失败和进行中的任务：

- ✅ **已保存**：点击“草稿 ↗”前往目标平台检查。
- ⏳ **等待确认**：开启了“更新草稿前确认”时，需在记录中再次确认才会写入。
- ❌ **失败或需处理**：按诊断提示处理登录、图片或平台接口问题。
- ⚠️ **保存结果不确定**：先查看目标草稿箱。此类任务不参加批量重试，单条重试需二次确认，以免重复创建。

> 🛡️ 再次同步可能覆盖对应草稿的手工修改，建议开启“更新草稿前确认”。CSDN 无法确认文章仍是草稿时会暂停更新；明确已删除的旧草稿会另存新草稿。删除或清空本地同步记录不会删除目标平台草稿；清空操作需等待进行中的任务结束。

## ⚙️ 偏好设置

- 🎯 **平台默认选择**：控制同步弹窗首次检测后的默认勾选，不表示自动发布。
- 📂 **CSDN 分类专栏**：自动读取已有专栏、设置默认分类，或按掘金标签匹配分类。
- 🖼️ **CSDN 内容选项**：封面、摘要、首发来源声明和图片转存失败策略。
- 🛡️ **更新草稿前确认**：已关联草稿的再次同步先进入待确认状态，防止误覆盖。

## 💡 使用边界与常见问题 (FAQ)

**❓ 同步后还需要重新上传图片吗？**
> 正常情况下不需要：扩展会自动转存正文图片和已有源封面。若图片源站防盗链拒绝下载、格式不被目标平台支持等情况仍可能转存失败，请查看诊断信息。微信正文图转存失败时会安全终止，绝不会把缺少图片的残缺文章当成成功。

**❓ 代码块会与掘金完全相同吗？**
> 微信不会复制掘金的 CSS 样式。微信代码块按微信公众平台专用的编辑器结构输出，完整保留代码行与缩进；颜色、高亮及手机端排版以微信官方编辑器渲染为准。

**❓ 为什么需要保持平台登录？**
> 扩展直接复用浏览器自身的官方登录会话，不代替扫码登录，也不绕过验证码或平台风控机制。登录状态失效时前往对应平台重新登录即可。

**❓ 更新微信草稿失败会新建一篇吗？**
> 不会。扩展已修复异常处理逻辑，不会把偶发网络抖动或接口报错当成“草稿不存在”，有效防止微信草稿箱产生多篇重复垃圾草稿。

**❓ 扩展重新加载后没有出现同步按钮？**
> 请刷新掘金页面，并确认正在自己的编辑器或文章管理入口操作。仅重新加载扩展不会自动替换已打开标签页里的旧脚本。

## 🔒 权限与隐私

- 🛡️ **零凭证托管**：不申请 `cookies` 敏感权限，不保存账号密码，绝不将登录凭据上传至任何第三方服务器。
- 💻 **本地数据安全**：本地存储仅包含设置、任务元信息、账号标识和草稿映射，历史记录不持久化全文 Markdown。
- ⚠️ **安全提醒**：微信草稿链接可能包含临时页面 token，请勿公开分享未经脱敏的存储导出、日志或链接。

| 🔑 权限或访问范围 | 📝 用途 |
| --- | --- |
| `storage` | 保存偏好设置、任务状态与草稿映射 |
| `notifications` | 后台长耗时同步结果系统通知 |
| `alarms` | 定期检查平台兼容性状态 |
| `declarativeNetRequestWithHostAccess` | 为已声明的平台接口补充必要请求头 |
| 掘金及声明的图片 CDN | 注入同步入口、读取源草稿和下载图片 |
| CSDN API 与图片存储服务 | 检查登录、读取分类、上传图片和保存草稿 |
| 微信公众平台 | 检查登录、上传/裁剪图片和保存草稿 |
| 博客园后台与图片服务 | 检查登录和博客开通状态、上传图片及保存随笔草稿 |

完整说明详见 [隐私政策](PRIVACY.md)、[安全说明](SECURITY.md) 和 [manifest.json](manifest.json)。
