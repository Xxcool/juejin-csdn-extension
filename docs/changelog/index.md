# 版本更新日志 (Changelog)

本项目遵循 [Semantic Versioning (语义化版本规范)](https://semver.org/lang/zh-CN/)。

## [0.6.0] - 2026-09-17

### ✨ 新增特性
- **CSDN 分类专栏动态拉取**：设置页默认分类输入框支持从当前登录账号实时拉取个人专栏列表（datalist 下拉建议），无需再手动翻查分类名。
- **正文摘要自动生成**：优先使用掘金作者手填摘要（`brief`），缺失时从正文自动提取前 100 字纯文本（剥离代码块、图片、链接与行内标记），写入 CSDN 编辑器摘要字段；偏好设置可随时开关。
- **掘金首发声明注入**：同步时在正文末尾追加「本文首发于掘金」引用声明（尊重平台原创规则，不占用转载 `original_link` 字段）；偏好设置可开关。
- **长耗时任务 Chrome 原生系统通知**：任务耗时 ≥ 10 秒或外链图片 ≥ 3 张时播报结果，点击通知直达 CSDN 草稿页；短任务保持安静不打扰。
- **同步前 Dry-run 排版预演**：任务卡片新增「预演」按钮，静态分析标题长度、正文字数、分类命中、外链图片数、掘金容器与代码围栏数量并弹窗展示风险清单，全程不转存图片、不写入草稿。
- **掘金图片无水印直链提取**：转存前剔除掘金 CDN 的 `~tplv-` 模板段与 `x-oss-process` 水印参数获取原始图，直链失效时自动回退原链接。
- **轻量远程健康检查**：每 12 小时后台拉取仓库发布的 `health.json` 状态文件，任一平台接口 broken 时在弹窗顶部显示警示条，可一键跳转状态页；检查失败静默降级，绝不阻断同步。

### 🛠️ 缺陷修复与自愈
- **修复 CSDN 侧草稿被删除后任务永久卡死**：更新模式遇到 400「该文章不存在」时自动降级为新建草稿，新文章 ID 自动覆盖旧映射，实现自愈；降级时复用已转存图片，不重复下载上传。
- **修复成功系统通知永不触发**：任务保存成功后构建通知对象时显式标记 saved 状态。
- **修复远程健康检查定时器失效**：MV3 Service Worker 每次唤醒重跑顶层代码导致同名 alarm 计时不断重置，改为先检查已存在再创建；同时新增 12 小时缓存防抖，缓存有效期内不再重复发起网络请求。
- **修复同步预演风险清单常黄**：首发声明注入属功能告知而非风险，拆分至独立的中性提示区，配置完备的合规文章可正常展示绿色就绪态。
- **修复快速失败任务被静默吞掉通知**：失败/需用户介入的任务豁免 10 秒时长门槛，避免用户切走后误以为同步成功。
- **修复任务数量为 0 时同步记录徽章仍显示空胶囊**：0 时完全隐藏。
- **CSDN 分类接口字段做 categories 拼写兼容防守**（实测服务端下发为拼写错误的 categorys）。
- **修复弹窗 CSS 显示问题**：修复 `hidden` 属性覆盖、预演报告长标题单行截断、弹窗内容超高时滚动失效问题。
- **通知点击兜底打开 popup.html 时在独立标签页居中展示**，不再缩在左上角。

### 🧪 自动化测试
- 新增 12 项 v0.6.0 专项测试：全量 41 项单测 100% 通过。

## [0.5.3] - 2026-09-17

### ✨ 新增
- 新增二级 Tab（筛选标签）集成式微胶囊轨道，支持选中态日光白药丸与动态数量角标。
- 新增任务卡片「草稿 ↗」蓝色高光实体渐变按钮与 1px 精细微边框状态徽章。
- 新增进行中任务进度条动态微光航线流光动效（`lightShimmer`）。

### 🛠️ 修复
- 修复双 Tab 滑块位移多出 2px 偏移的问题，实现两端 1:1 绝对物理对称（标准 3px 边距）。
- 修复「偏好设置」与「同步记录」外边距对齐为 14px。
- 修复 CSDN 在线绿点呼吸光晕扩散范围，动效更加轻盈克制。

## [0.5.2] - 2026-09-17

### ✨ 新增
- 新增「旗舰工艺版」现代设计系统：专属一叶轻舟破浪摆渡舰徽、CSDN 在线状态呼吸光晕、物理弹簧分段滑块。
- 新增「渡口夜灯」空状态温感插画与清晰实用的 3 步实操指南。

### 🛠️ 修复
- 任务运行态完整展示 `task.progress.message`（例如「正在转存图片 3/10」）与实时百分比。
- 扩展版本号改为通过 `chrome.runtime.getManifest()` 动态注入，杜绝硬编码漂移。

## [0.5.1] - 2026-09-16

### 🛡️ 可靠性与安全防御
- 新增 CSDN 线上已发布博文状态检测：写入草稿前查询文章发布状态，已发布文章物理阻断覆盖同步。
- 任务历史 Storage 瘦身：持久化剥离全量 Markdown 正文并在升级时自动迁移存量数据，根除 `storage.local` 10MB 配额爆仓风险。
- 后台任务执行引入全局并发闸门（Semaphore，上限 2），批量重试不再突发并发，杜绝触发平台 429 限流。
- 引入结构化错误体系（`SyncError`：错误类别 + 阶段），失败归因与修复建议精准度全面提升。
- 新增掘金容器语法清洗：`:::tips` 等内置容器自动转换为标准 Markdown 引用块。

## [0.4.0 ~ 0.5.0]


- 弹窗重构为一体化双 Tab 仪表盘布局，打开即见同步任务与草稿链接。
- 新建文章在点击“确定并发布”时立即创建 CSDN 同步任务，不阻塞掘金发文。
- 历史文章同步支持双身份草稿映射，避免重复生成草稿。
- 支持默认 CSDN 分类，以及“掘金标签 → CSDN 分类”映射。
