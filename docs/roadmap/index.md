# 产品路线图与演进规划 (Roadmap)

本文档呈现「文章摆渡」的长期愿景、核心演进阶段与功能储备池。

## 🎯 发展路线图阶段规划

### 第一阶段：基准打磨与单线极致稳定（v0.5.0 ~ v0.6.0，已完成 ✅）
- [x] 重构双 Tab 扁平仪表盘与 Design Tokens
- [x] 自适应深色模式与 Raycast 质感 UI 2.0
- [x] CSDN 在线呼吸光晕状态胶囊与健康检测预警
- [x] 无水印高清原图直链提取与通用容器清洗
- [x] 同步前排版预演 (Dry-run) 零副作用分析
- [x] 400 删稿自愈降级新建与双身份草稿幂等
- [x] Chrome 原生系统通知长耗时触发
- [x] 存储瘦身防爆仓与结构化脱敏诊断

### 第二阶段：创作者数据资产安全与备份（v0.7.0 ~ v0.8.0，进行中 🚧）
- [ ] **【杀手级】掘金个人博客一键全量本地备份**：
  - 一键将作者本人的全部掘金文章、分类、标签连同高清图床图片，打包下载为离线 ZIP 归档；
  - 彻底消除技术博主对“平台封号/接口下线/数据丢失”的隐性数据焦虑；
- [ ] **导出为标准 Hugo / Hexo / Astro 静态博客格式**：
  - 自动生成 YAML Frontmatter 头信息（含 `title`、`date`、`tags`、`categories`）；
  - 方便博主将掘金内容无缝转换为个人独立博客。

### 第三阶段：多平台矩阵扩张（v1.0.0 目标 🌟）
- [ ] **微信公众号草稿箱摆渡**：
  - 基于端侧拦截同步生成微信公众号图文草稿；
  - 微信富文本样式渲染引擎注入（代码块横向滚动防换行、排版主题预设）；
- [ ] **博客园 (Cnblogs) 摆渡适配**：
  - 接入 MetaWeblog XML-RPC 规范或官方 MetaWeblog API；
  - 适配博客园 Markdown 编辑环境；
- [ ] **知乎专栏草稿箱适配**：
  - 探索端侧知乎专栏草稿写入通道。

## 🛡️ 架构演进红线原则


无论产品如何迭代扩张，以下红线永不妥协：
1. **坚决不替用户公开发布**：确认权永远在目标平台草稿箱；
2. **坚决不引入中心化第三方代理服务器**：计算全在端侧完成；
3. **坚决不向用户索要平台登录密码或 Cookie**。
