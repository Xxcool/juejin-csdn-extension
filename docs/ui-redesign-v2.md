---

## 1. 设计初衷与改版诊断

旧版 UI 虽功能完整，但存在以下“传统管理后台（Admin Dashboard）”通病：
1. **卡片泛滥（Card Overuse）**：设置页将每个开关单独包裹为悬浮白块，视觉零散割裂；
2. **Tab 风格陈旧**：下划线滑动条容易使人联想到 2018 年代旧式企业 ERP 系统，缺乏紧凑感；
3. **顶栏状态喧宾夺主**：厚重绿底绿框挤占标题视觉中心；
4. **卡片信息冗余**：折叠嵌套增加点击成本，“同步成功”重复出现；
5. **空状态冷清荒凉**：仅有灰色孤立图标，缺少情绪共鸣与新手路径指引。

---

## 2. 核心设计原则

- **Content-First（内容为王）**：任务卡片取消折叠展开，一次性清晰呈现标题、耗时、图片转存状态与直达入口。
- **Grouped Hierarchy（内嵌聚合）**：遵循 iOS / Raycast 规范，相关联的配置项聚合在统一的大圆角容器内，以细微边框分割。
- **Tactile Micro-interactions（触感微交互）**：分段滑动药丸（Segmented Control）、动态呼吸状态点、柔和平滑的 Switch 开关。
- **Warm Onboarding（温感引导）**：空状态转变为新用户上手指引，附带 3 步可视化流程。

### 3.2 质感阴影与高光 (Elevation & Shadows)

- **`--shadow-sm`**：`0 1px 2px 0 rgba(0, 0, 0, 0.04)` —— 普通卡片与微元素
- **`--shadow-md`**：`0 4px 12px -2px rgba(0, 0, 0, 0.06), 0 2px 4px -1px rgba(0, 0, 0, 0.04)` —— 悬停上浮与浮动滑块

- **`--spring-snappy`**：`cubic-bezier(0.2, 0.9, 0.2, 1.25)` —— 弹性滑块与触感物理曲线

## 4. 核心组件重构规范 (旗舰工艺版)

### 4.1 顶栏与专属摆渡舰徽（Ferry Emblem & Brand Motto）
- 左侧：28x28px 专属摆渡舰徽（一叶轻舟破浪）+ 13.5px 粗体标题 + 动态版本号微标签 + 副标「一键摆渡 · 草稿安全着陆」；
- 右侧：呼吸光波绿环胶囊（`🟢 用户名`），带有扩散光晕动画，点击可主动检测或刷新授权。

### 4.2 物理弹簧滑块分段控制器（Spring Segmented Control）
- 结构：浅灰底跑道（`#f1f5f9`）内嵌带有日光高光与物理弹簧轨迹的白色滑块（`.spring-thumb`）；
- 动效：`transition: transform 0.28s var(--spring-snappy)` 伴随按压回弹微缩放；
- 包含未读数字微徽标（Badge）。

### 4.3 任务记录卡片（Craftsman Task Card）
- 结构扁平化，顶置双层日光极细边框；
- 进行中任务具备 `.task-progress-box`，完整渲染 `task.progress.message`（如「正在转存图片 3/10」）与百分比；`total=0` 具备流光穿梭动效；
- 底部精细分割线隔离出耗时统计与右侧操作按钮组（“草稿 ↗”主要操作 + “删除”幽灵图标）。

### 4.4 偏好设置集合卡片（Grouped List & Haptic Switch）
- 顶部保留 11px 大写字母分组标题（`SYNC & PUBLISH`）；
- 容器为一整块带日光高光的白色圆角卡片，项与项之间以 `border-light` 细线分割；
- 开关具备机械触感弹性物理回弹（`--spring-snappy`）。
- 完整包含所有原有设置与安全隐私声明卡片。

### 4.5 新手空状态（The Quiet Harbor · 渡口夜灯微光）
- 顶置水波涟漪（`.water-ripple`）与轻微上下浮动的轻舟卡片（`.harbor-boat-card`）及微光绿星；
- 友好文案：“准备就绪，开启摆渡”；
- 醒目的“前往掘金文章管理”微光渐变主按钮；
- 底部 3 步可视化实操指引卡（`① 掘金写完` · `② 勾选同步` · `③ 草稿直达`）。

### 4.6 视口规范（Golden Viewport & Flex Engine）
- 视口严格设定为 380px 宽 × 470px 高（~1.2 紧凑黄金比例）；
- 主链路 `.tab-pane`、`.task-list`、`.settings-scroll` 均强制挂载 `min-height: 0;` 与 `overflow-y: auto;`，杜绝 Flex 溢出假死；
- 配备 5px Mac 风格极细半透明圆角滚动条。

## 5. 验收与无障碍标准

1. **WAI-ARIA**：Tab 切换保持 `role="tablist"` / `role="tab"` / `role="tabpanel"`，键盘 `←` / `→` 键平滑切换焦点；
2. **深色模式**：系统级 `prefers-color-scheme: dark` 全量自适应，对比度符合 WCAG AA 级；
3. **性能**：纯 CSS 变量与现代 Flex/Grid 布局，0 第三方 UI 库，包体积无膨胀。
