# 项目介绍与设计原则

**「文章摆渡」** 是一款基于 Chrome Manifest V3 规范打造的去中心化、端侧安全的内容同步工具。以掘金（Juejin）为核心创作入口，在创作者明确勾选确认后，将新发布或历史文章可靠地同步至 CSDN 草稿箱。

## 🎯 核心护城河与设计准则


### 1. 极致的安全信任（Zero-Trust & Local-First）
- **零 Cookie 权限申请**：扩展在 `manifest.json` 中**坚决不声明 `cookies` 权限**，不读取亦不收集用户的账号密码或跨域 Cookie。
- **本地端侧闭环**：所有的 Markdown 文本清洗、DOM 提取、图片防盗链跨域代理与 CSDN 草稿生成均在您的本地浏览器进程（MV3 Service Worker）中执行，绝不经过任何第三方云服务。
- **开源可审查**：所有代码在 GitHub 完全开源，构建脚本与发布流程公开透明。

### 2. 人机协作的发布边界（Human-in-the-loop）
> [!IMPORTANT]
> **工具专注消灭 90% 的机械搬运、格式清洗与图床转存工作，坚决不替用户公开发布。**
- 分类、标签微调以及最终的“确认公开发布”权利，永远保留在目标平台（CSDN）的草稿箱编辑页面中。
- 这一红线从根源上保障了创作者的版权安全与平台运营合规，避免因自动化漏洞造成草率发文。

### 3. 可靠性工程底座（Reliability Engineering）
- **双身份幂等映射**：基于 `article_id`（掘金文章唯一标识）与 `draft_id`（目标平台草稿 ID）映射管理，重复同步原地覆盖，绝不污染草稿箱。
- **三路有限并发与退避**：面对包含数十张图片的深度长文，内置三路并发队列与指数退避（Exponential Backoff）重试，杜绝触发平台 429 限流。
- **存储防爆仓设计**：Chrome 扩展 `storage.local` 具备 10MB 配额上限。文章摆渡采用正文按需拉取模式，元数据瘦身存储，支撑数千篇同步记录不瘫痪。

## 🏗️ 架构概览

```
[掘金创作者平台]
  │  （发布面板勾选 / 历史文章管理列表点击）
  ▼
[Content Script & DNR 拦截]
  │  提取文章标题、摘要、无水印原图、标准 Markdown
  ▼
[Chrome MV3 Service Worker (文章摆渡调度核心)]
  ├─ 1. 静态排版分析 & Dry-run 校验
  ├─ 2. CSDN 会话在线心跳与分类专栏匹配
  ├─ 3. 高清图床并发流式搬运（去水印）
  └─ 4. CSDN 草稿箱幂等保存 / 400 自愈
  ▼
[CSDN 草稿箱] ────▶ 创作者做最终检阅并自主发布
```
