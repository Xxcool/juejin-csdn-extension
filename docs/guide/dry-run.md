# 同步前排版预演 (Dry-run)

在内容跨平台同步中，许多创作者最担心的就是“一次误操作导致草稿箱产生数篇废稿”、“图片格式转错了撤销麻烦”或者“排版在目标平台崩塌”。

针对这些痛点，文章摆渡在 **v0.6.0** 引入了创新的 **同步前排版预演 (Dry-run)** 机制。

## 什么是排版预演？

排版预演是一种**完全零副作用、纯内存静态分析**的校验流程：

> [!IMPORTANT]
> **全流程不写草稿、不传图片**  
> 预演过程中，扩展仅在本地提取并解析 Markdown 内容结构，不会向 CSDN 草稿箱写入任何数据，也不会将任何图片上传至 CSDN 图床，从源头上杜绝测试废稿。

## 预演检测的核心指标

当您触发预演时，扩展将即时生成一份结构化的体检诊断报告：

| 检测项 | 说明 | 诊断标准与价值 |
| :--- | :--- | :--- |
| **标题合规度** | 检查标题长度与敏感字符 | 提前预警标题是否过长或为空 |
| **正文字数与耗时** | 统计纯文本字数与预估阅读时间 | 评估文章体量，若包含超大篇幅将自动启用分块防抖 |
| **分类命中情况** | 匹配 CSDN 现有专栏与默认分类 | 明确显示将写入哪一个专栏，避免分类错放 |
| **待转存图片清单** | 识别正文所有外链图片与封面图 | 提前解析掘金 CDN 去水印原图直链，统计待转存图片总数 |
| **平台专属语法容器** | 检测掘金特有 `:::tips`、`:::note` 容器 | 预演转译为标准 Markdown 引用块后的效果 |
| **代码块围栏合规** | 统计代码块数量与未闭合围栏 | 避免因反引号缺失导致整篇文章后续代码渲染穿透 |
| **首发声明注入告知** | 预演文章尾部自动追加的声明文案 | 提示 `> 本文首发于掘金：[标题](链接)` 的注入状态 |

## 如何进行预演？


1. 打开扩展弹窗的 **「同步记录」** 面板；
2. 在任意文章任务卡片底部，点击 **“预演”** 按钮；
3. 扩展将立即弹出「排版预演报告」弹窗；
4. 弹窗顶部呈现就绪态状态指示：
   - 🟢 **就绪 (Ready)**：所有校验项均合规，无排版阻塞风险；
   - 🟡 **注意提示 (Notice)**：存在部分待关注项（如包含较多外链图、未配置专栏分类等），点击可查看细节；
5. 检阅无误后，点击卡片上的“同步”按钮正式摆渡，安全无忧！
