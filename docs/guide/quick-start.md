# 3 分钟快速上手指南

本指南将带领您完成第一次跨平台文章摆渡。整个过程平滑顺畅，无需记忆复杂的命令。

## 准备工作：检查登录态

「文章摆渡」遵循端侧零信任原则，直接复用您在浏览器标签页中的现有会话：

1. **登录掘金**：在浏览器标签页打开并登录 [juejin.cn](https://juejin.cn)；
2. **登录 CSDN**：在另一个标签页打开并登录 [csdn.net](https://www.csdn.net)；
3. **点击扩展图标查看状态**：
   - 点击浏览器右上角「文章摆渡」扩展图标；
   - 顶部状态胶囊应显示带呼吸光晕的 **🟢 CSDN 在线**；
   - 若显示“未登录”，点击胶囊即可在新标签页直达 CSDN 登录页。

## 场景一：撰写新文章时自动同步（核心流程）


在掘金正常编写技术博文，文章摆渡已与发文交互无缝整合：

1. **正常编写与排版**：在掘金 Markdown 编辑器完成博文编写；
2. **点击发布**：点击编辑器右上角的 **“发布”** 按钮；
3. **确认同步勾选**：
   - 掘金发文弹出抽屉中，文章摆渡会自动注入同步控制组件；
   - 默认已为您勾选 **“同步到 CSDN 草稿”**；
4. **确定并发布**：
   - 点击掘金的 **“确定并发布”**；
   - 掘金进入正常的官方审核与发文流程；
   - 同时，后台扩展 Service Worker 自动启动流水线，在后台静默完成：
     - 正文摘要提取；
     - 原创声明注入（`> 本文首发于掘金：...`）；
     - 高清图片去水印与 CSDN 图床转存；
     - 生成 CSDN 对应专栏草稿；
5. **系统通知与直达草稿**：
   - 同步完成后，Chrome 将弹出系统通知；
   - 点击通知或点击扩展弹窗中的 **“草稿 ↗”** 按钮，即可直达 CSDN 草稿编辑界面！

## 场景二：历史旧文批量一键摆渡

如果您在掘金已有多年积累的精选历史博文，想要迁移至 CSDN：

1. 进入掘金 **创作者中心 ➔ 内容管理 ➔ 文章管理**（`juejin.cn/creator/content/article`）；
2. 在文章列表中，找到您想迁移的博文；
3. 文章卡片右侧将出现专属的 **“摆渡到 CSDN”** 快捷按钮；
4. 点击后后台自动建立队列并异步处理，无需长时间停留在页面等待；
5. 打开扩展弹窗的「同步记录」面板，即可实时查看所有迁移任务的完成度。

## 场景三：在 CSDN 草稿箱最终确认发布


> [!TIP]
> **人机协作的核心准则**：文章摆渡将博文安全保存至 CSDN 草稿箱后，**绝不自动替您公开发布**。

打开 CSDN 草稿编辑页后，您可以进行最终确认：
- **分类专栏**：扩展已根据偏好设置或专栏建议为您自动选定分类专栏；
- **排版检查**：检查代码高亮、高清原图、表格与引用样式；
- **自主发布**：确认无误后，点击 CSDN 的 **“发布文章”** 完成跨平台分发。
