# 发布前验收清单

本文用于每个版本发布前的人工冒烟验证。测试文章和错误信息不得包含账号凭据或未公开内容。

## 准备

- 在同一 Chrome 中加载最新 `dist`，并分别准备已登录和未登录 CSDN 的环境。
- 准备一篇包含封面、普通图片、代码块和标签的掘金测试文章。
- 运行 `npm run check`、`npm test` 和 `npm run build:release`。

## 核心场景

1. **新文章首次同步**：从掘金发布面板勾选 CSDN，发布成功后生成一篇 CSDN 草稿，标题、正文、代码块、标签、封面和图片可用。
2. **同一文章再次同步**：修改并再次同步同一篇文章，只更新已有 CSDN 草稿，不生成重复草稿。
3. **历史文章同步**：从本人文章列表发起同步，能读取完整 Markdown 并生成草稿。
4. **登录续接**：退出 CSDN 后同步历史文章，完成登录并返回掘金，任务能够继续。
5. **正文图片部分失败**：模拟一张正文图片不可访问，草稿仍保存，保留原链接并显示图片失败统计和警告。
6. **封面转存失败**：模拟封面不可访问，草稿仍保存且不设置封面，历史记录显示警告。
7. **任务恢复**：在图片处理阶段重载扩展后任务可恢复；在首次创建草稿写入阶段中断时，提示先检查草稿箱，不自动重复创建。

## 结果记录

- 记录 Chrome、扩展版本、验证时间和每项结果。
- 失败项需附复现步骤、发生阶段和脱敏后的诊断信息；核心场景全部通过后才能生成 Release ZIP。
