# 旗舰工艺 UI 2.0 (Craftsmanship UI)

软件不仅应该功能可靠，更应该带给使用者愉悦、精致的触感。文章摆渡在经历了 **UI 2.0** 深度重构后，全面确立了以“旗舰级工艺设计”为基准的视觉与交互规范。

## 🎨 设计系统与 Raycast 质感

UI 2.0 汲取了现代效率工具（如 Raycast、Linear）的设计精髓，彻底重构了浏览器插件弹窗的视觉质感：

- **一叶轻舟专属舰徽**：采用全新设计的矢量舰徽（`logo.svg`），象征在多平台知识海洋中平稳摆渡；
- **微胶囊筛选轨道**：任务记录支持按状态过滤，选中态呈现日光白圆角药丸，配合精准数量角标（如 `2/8 篇`），告别信息歧义；
- **物理弹簧滑块**：顶部分段导航（「同步记录」与「偏好设置」）拥有平滑的位移动效与绝对对称的物理边距（两端 1:1 绝对 3px 边距），丝滑无缝；
- **状态呼吸光晕**：CSDN 登录在线态采用受控的柔和呼吸绿光波纹，实时感知连接状态而不显刺眼喧闹。

## 🌓 自适应深色模式 (Adaptive Dark Mode)

许多开发者习惯在夜间进行创作与技术整理。如果插件弹窗弹出强烈的白光，会对双眼造成强烈的刺激与疲劳。

文章摆渡内置基于 **Design Tokens** 的全栈深浅色切换机制：
- **无感跟随**：自动同步操作系统或浏览器的深浅色外观偏好；
- **暗夜高对比度**：采用深空灰（`#0e1117`、`#161b22`）层次底色，搭配冷色调微弱描边与微高光（Hairline Top），文字清晰锐利而不失柔和；
- **无抖动过渡**：颜色变量通过 CSS Variables 动态注入，模式切换平滑无闪烁。

## 🔔 Chrome 原生系统通知

传统插件必须在弹窗打开的状态下才能查看进度，一旦用户点击其他页面，弹窗关闭后就无法感知后台任务是否成功。

文章摆渡接入了 Chrome 原生桌面通知体系，并制定了**克制优雅的通知阈值**：

| 触发场景 | 通知行为 | 用户交互 |
| :--- | :--- | :--- |
| **短小轻量任务**（耗时 < 10 秒且图片 < 3 张） | 静默保存，不打扰创作思考 | 弹窗记录可查 |
| **长耗时 / 多图搬运**（耗时 ≥ 10 秒或图片 ≥ 3 张） | 任务完成时弹出桌面横幅通知 | **点击通知直接跳转并打开 CSDN 草稿编辑页** |
| **任务失败 / 需用户介入** | 立即豁免门槛弹出错误警示 | 避免用户切走后产生“误以为已成功”的错觉 |

## 📋 结构化脱敏诊断


当任务遭遇异常时，插件不只输出冷冰冰的“同步失败”：
- 将故障精准细分为 **8 类异常**（网络、会话、解析、限流、配额、鉴权等）与 **6 大执行阶段**；
- 提供 **“一键复制脱敏诊断信息”** 功能：自动剔除用户的个人 Cookie、未公开文章正文等私密数据，仅保留错误码、状态机阶段与报错堆栈，极大地简化了向开源社区反馈排错的沟通成本。
